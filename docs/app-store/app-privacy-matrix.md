# WinterWatch-Pro App Privacy Matrix

Last updated: July 30, 2026

Use this when filling out the App Privacy section in App Store Connect.

## Data Linked To The User

- Name
  Purpose: App functionality, account management
- Email Address
  Purpose: App functionality, account management
- Precise Location
  Purpose: App functionality
- Photos or Videos
  Purpose: App functionality
- User Content
  Purpose: App functionality, customer support

## Data Not Linked To The User

- Product Interaction
  Purpose: Analytics, app functionality
- Crash Data
  Purpose: Analytics

## Tracking

- Tracking: `No`
- Third-party advertising tracking: `No`
- Data broker / ad measurement use: `No`

## Notes

- WinterWatch-Pro uses precise location to record check-in/check-out activity and help identify nearby service accounts.
- Photo uploads are used for work logs and service verification.
- User-entered notes, work-log text, and operational content should be treated as user content.
- If you later add analytics, session replay, ads, or customer chat SDKs, re-audit this matrix before the next submission.
